# Our changes to other projects

Each file here describes a change Nyra makes to another project (bootc, systemd, …): what it fixes,
why, and the change itself. We keep these changes as our own patches and apply them in our builds;
we do not send them to the projects.

project or send it upstream yourself, with no need to ask and no obligations.

once applied, the result is under the project's licence, as before.
